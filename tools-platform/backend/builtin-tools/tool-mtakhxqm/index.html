核心规律小贴士 💡

Ibn (ابن / 伊本) = ...的儿子

Bint (بنت / 宾特) = ...的女儿

只要搞清长辈是 Amm(叔伯), Amma(姑), Khāl(舅), Khāla(姨)，后面直接加上 Ibn 或 Bint，就能组合出所有的表/堂亲称呼了！

性别区分注意 ⚠️

阿拉伯语中很多词区分说话人的性别。例如“想要”：男生说 'āyez (عايز)，女生说 'āyza (عايزة)。

“有/没有”神句：mawgūd (有) / mafīsh (没有)，走遍埃及都不怕！

28 个阿拉伯语字母

认识字母在不同位置的写法，并分别练习字母名称、短元音和无元音收尾。

为什么一个字母有多种读音？ 字母本身主要表示辅音，例如 بَ / بِ / بُ 分别读 ba / bi / bu，بْ 表示 b 后面没有元音。字母在词首、词中、词尾会改变形状，但通常仍是同一个音。埃及方言和标准语有差异的字母会在卡片下方特别标出。

字母 و（wāw：w / ū / aw）

و 不与左边下一个字母连接，写法始终保留圆钩形。它既可作辅音 w，也可承担长音 ū；加静音符并跟在 fatḥah 后常组成双元音 aw。

字母 ي（yāʾ：y / ī / ay）与 ى

笔记里是带两点的 ي：可作辅音 y，也可承担长音 ī。你输入的 ى 没有点，叫 alif maqṣūrah，只出现在词尾，通常读长音 ā。

ا、أ、إ（alif 与 hamza）

ا 通常是长音 ā 的载体，本身不是像 ب、ت 那样的辅音。词首短音由 hamza 承担：أَ = ʾa、إِ = ʾi、أُ = ʾu；长 ī、ū 则写作 ي、و。

连写规则

关键点：阿拉伯语从右向左书写，并非所有字母都能连接左边的下一个字母。

✅ 可以向两侧连接：ب、ت、ث、ي

它们在单词中会根据位置呈现独立、词首、词中和词尾写法。

ب　بـ　ـبـ　ـب

🚫 不连接左边的下一个字母：ا、و、ى

ا 和 و 可以接在前一个字母后面，但会让后续连接中断；ى 通常出现在词尾，也不再向后连接。

بـاـب ❌
错误：ا 后面仍画了连接线
بَاب ✅
正确：ا 后断开，最后的 ب 独立

ج = g
ج 大部分情况读 g
在开罗/埃及方言中，ج 大部分读作硬 g（如 gamal 骆驼、gesr 桥、gobn 奶酪）。
ُ ≈ o
闭口符 ُ 经常偏向 o
短元音 ُ 在埃及口语中常弱化接近中圆唇元音 o（如 gobn 奶酪、ḥobb 爱、ḥosān 马）。
ح / خ
严格保留深喉音
清咽擦音 ح 与小舌擦音 خ 必须保持喉部摩擦发音质感（如 ḥagar 石头、baḥr 海）。
َ ِ ُ ْ ّ
保留完整发音符号
短音符号省略时极易产生词性与词意歧义（如 ḥagar 石头 vs ḥagr 限制/隔离），故全量保留。

规则 1 标准 العربية → 埃及口语实际音变
标准语长句在口语中往往更加紧凑口语化，提问与否定发生词汇级替换：
标准语：كَيْفَ حَالُكَ？ (你好吗？男) → 埃及口语：إِزَّيَّك؟
标准语：كَيْفَ حَالُكِ？ (你好吗？女) → 埃及口语：إِزَّيِّك؟
标准语：هَذَا / هَذِهِ (这个) → 埃及口语：دَه / دِي
标准语：لَيْسَ (不是) → 埃及口语：مِش
规则 2 男性 vs 女性词尾区别律
面对不同性别对象时，词尾代词及问候有严格对应的阳性/阴性规律：
👨 对男性：尾缀 ـكَ (-ak)，如 اِسْمَك (你的名字·男)、إِزَّيَّك؟、أَهْلًا بِيك
👩 对女性：尾缀 ـكِ (-ik/-ek)，如 اِسْمِك (你的名字·女)、إِزَّيِّك؟、أَهْلًا بِيكِ
规则 3 亲爱的人称区分（称呼伴侣/朋友）
日常生活极高频的亲切爱称，严格区分男女对象：
👨 男性对象：حَبِيبِي (ḥabiibi) = 我的亲爱的 / 亲爱的朋友
👩 女性对象：حَبِيبَتِي (ḥabiibti) = 我的亲爱的 / 亲爱的（女）
阶段重点 从“字母发音”贯通到“日常会话第一课”
之前练习的 ح / ج / خ / ش 咽喉音与擦音，直接实战无缝融入日常会话核心词：
• ح → حَبِيب (亲爱的) · حِجَاب (头巾)
• ج (读 g) → حِجَاب (he-gaab) · وَاجِب (waa-gib)
• خ → أَخْبَار (新闻/消息)
• ش → شَارِع (街道) · مِش (不是)
