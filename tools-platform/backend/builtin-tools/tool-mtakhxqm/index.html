核心规律小贴士 💡

Ibn (ابن / 伊本) = ...的儿子

Bint (بنت / 宾特) = ...的女儿

只要搞清长辈是 Amm(叔伯), Amma(姑), Khāl(舅), Khāla(姨)，后面直接加上 Ibn 或 Bint，就能组合出所有的表/堂亲称呼了！

性别区分注意 ⚠️

阿拉伯语中很多词区分说话人的性别。例如“想要”：男生说 'āyez (عايز)，女生说 'āyza (عايزة)。

“有/没有”神句：mawgūd (有) / mafīsh (没有)，走遍埃及都不怕！

28 个阿拉伯语字母

认识字母在不同位置的写法，并分别练习字母名称、短元音和无元音收尾。

为什么一个字母有多种读音？ 字母本身主要表示辅音，例如 بَ / بِ / بُ 分别读 ba / bi / bu，بْ 表示 b 后面没有元音。字母在词首、词中、词尾会改变形状，但通常仍是同一个音。埃及方言和标准语有差异的字母会在卡片下方特别标出。

字母 و（wāw：w / ū / aw）

و 不与左边下一个字母连接，写法始终保留圆钩形。它既可作辅音 w，也可承担长音 ū；加静音符并跟在 fatḥah 后常组成双元音 aw。

字母 ي（yāʾ：y / ī / ay）与 ى

笔记里是带两点的 ي：可作辅音 y，也可承担长音 ī。你输入的 ى 没有点，叫 alif maqṣūrah，只出现在词尾，通常读长音 ā。

ا、أ、إ（alif 与 hamza）

ا 通常是长音 ā 的载体，本身不是像 ب、ت 那样的辅音。词首短音由 hamza 承担：أَ = ʾa、إِ = ʾi、أُ = ʾu；长 ī、ū 则写作 ي、و。

连写规则

关键点：阿拉伯语从右向左书写，并非所有字母都能连接左边的下一个字母。

✅ 可以向两侧连接：ب、ت、ث、ي

它们在单词中会根据位置呈现独立、词首、词中和词尾写法。

ب　بـ　ـبـ　ـب

🚫 不连接左边的下一个字母：ا、و、ى

ا 和 و 可以接在前一个字母后面，但会让后续连接中断；ى 通常出现在词尾，也不再向后连接。

بـاـب ❌
错误：ا 后面仍画了连接线
بَاب ✅
正确：ا 后断开，最后的 ب 独立
