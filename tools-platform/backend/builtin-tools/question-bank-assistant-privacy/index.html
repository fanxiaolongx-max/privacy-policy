01 · Scope

适用范围Scope

本隐私政策仅适用于由 Tools Platform 提供的“题库与答题助手”浏览器扩展。目标考试网站、浏览器商店、浏览器厂商以及您访问的其他网站均有各自的隐私政策，我们不控制这些第三方的处理行为。

This Privacy Policy applies only to the Question Bank & Answer Assistant browser extension provided through Tools Platform. Exam websites, extension stores, browser vendors, and other websites you visit have their own privacy practices, which we do not control.

核心原则：Core principle: 考试内容和题库在本地处理，扩展不会将其发送到 Tools Platform 或其他第三方。Exam content and question banks are processed locally and are not sent by the extension to Tools Platform or third parties.

03 · Purpose

我们如何使用数据How we use data

  • 建立本地题库：Build a local bank: 识别考试页中的题目、选项和答题反馈，整理成可搜索、可标注的本地题库。Recognize questions, options, and feedback on an exam page and organize them into a searchable, editable local bank.
  • 辅助答题：Assist answering: 在用户主动启动后，将当前题目与本地题库匹配，并在当前页面选择相应答案。After the user starts the tool, match current questions against the local bank and select corresponding answers on the current page.
  • 导入与导出：Import and export: 由用户主动将题库导出为 JSON，或从用户选择的 JSON 文件导入。Allow the user to export a bank as JSON or import a user-selected JSON file.
  • 授权和防滥用：Authorization and abuse prevention: 验证 License 有效期和状态、提供可信时间、限制异常频繁请求并协助安全排障。Validate License validity and status, provide trusted time, rate-limit abnormal requests, and support security troubleshooting.

我们不会将收集或处理的数据用于与上述功能无关的目的。

We do not use collected or processed data for purposes unrelated to the functions described above.

04 · Permissions

扩展权限说明Extension permissions

  • storage — 保存界面语言、License、可信时间和授权校验状态。Stores interface language, License, trusted time, and authorization status.
  • activeTab — 在用户点击扩展并主动启动时访问当前标签页。Accesses the current tab when the user opens and starts the extension.
  • scripting — 将题库与答题功能注入当前目标考试页面。Injects question-bank and answer-assistance functions into the current target exam page.
  • 网站访问权限：Host access: 用于在配置的目标考试网站运行，以及连接指定的 Tools Platform License 校验地址。扩展不会基于该权限建立浏览历史。Used to run on configured exam websites and connect to the specified Tools Platform License endpoint. This access is not used to build browsing history.
题库当前保存在目标网站对应的本地存储空间。清除该网站的浏览数据可能删除题库；反之，仅卸载扩展不一定会清除该网站已有的本地存储。Question banks are currently stored in browser storage associated with the target website. Clearing that site's browsing data may remove them; conversely, uninstalling the extension alone may not remove storage already held for that website.

我们不会出售用户数据，不会向数据经纪商提供数据，也不会使用数据进行个性化广告、信用评估或跨网站跟踪。

We do not sell user data, provide it to data brokers, or use it for personalized advertising, credit evaluation, or cross-site tracking.

授权校验数据仅由 Tools Platform 授权基础设施及其管理员处理。除非为遵守适用法律、保护用户或平台安全，或在用户明确要求下，我们不会向其他第三方披露这些数据。

License-validation data is processed only by the Tools Platform authorization infrastructure and its administrators. We do not disclose it to other parties unless required by applicable law, necessary to protect users or platform security, or explicitly requested by the user.

06 · Retention

数据保存与删除Data retention and deletion

  • 本地题库：Local banks: 保留在浏览器中，直到用户点击“清空当前题库”、覆盖导入，或清除目标网站的本地浏览数据。Remain in the browser until the user clears the current bank, replaces it through import, or clears local browsing data for the target website.
  • 扩展设置和 License：Extension settings and License: 保留在扩展本地存储中，直到用户清除扩展数据或卸载扩展。Remain in extension storage until the user clears extension data or uninstalls the extension.
  • 授权记录：Authorization records: License 的产品、签发、有效期和状态记录，以及必要的安全日志，按平台管理员的安全和运维保留策略保存。License product, issuance, validity, and status records, together with necessary security logs, are retained according to the platform administrator's security and operational retention policy.

如需查询或删除与 License 相关的服务器记录，请通过本政策末尾的联系方式联系管理员。依法必须保留或为安全审计所需的数据可能无法立即删除。

To request access to or deletion of server-side License records, contact the administrator using the details below. Records required by law or necessary for security audits may not be immediately deletable.

07 · Security

数据安全Data security

我们通过本地优先处理、最小化联网数据、HTTPS 授权校验、随机 nonce、防重放签名校验、ECDSA P-256 离线验签、请求限流及访问控制等措施降低数据风险。

We reduce data risk through local-first processing, minimal network data, HTTPS License validation, random nonces, signed anti-replay attestations, offline ECDSA P-256 verification, rate limiting, and access controls.

任何网络或存储系统都无法保证绝对安全。用户应妥善保管 License 和导出的题库文件，并只在可信设备和网站上运行扩展。

No network or storage system can guarantee absolute security. Users should protect License keys and exported question-bank files and run the extension only on trusted devices and websites.
