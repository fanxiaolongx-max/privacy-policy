# 胶片设计：自主履行愿景默认内容页

新建项目和“新增内容页”使用 `network_safety_meeting_summary/js/vision-template.js` 中的愿景模板。已有项目继续加载已保存的内容；历史布局保留在 `legacyDefaultSlides` 中。

模板参考已确认的 Canva 设计 `DAHXONTqENM`，画布为 1920×1080，包含 33 个文字对象和 41 个独立图片对象。四个指标标签“风险与整改、响应与恢复、收入与利润、能力与履职”均为可编辑文字。机关、地区部及自主履行的文案均可单独修改。

所有对象接入现有组件编辑器，支持位置、尺寸、旋转、图层、分组和删除等操作。图片素材固化在 `assets/vision/`，不依赖 Canva 临时签名地址。

愿景页通过 `vision-pptx.js` 导出独立文字和图片对象；其他历史页面保持原有导出方式。导出后文字可在 PowerPoint 中修改，图片可单独调整和替换。

高清修订：原整页背景为 199×112、平台为 198×89，属于被放大的 Canva 缩略图。现在背景为 3344×1882、平台为 1872×841，卡片、远景、规划条及分隔线也使用高清素材。几何背景的 SVG 源稿保留在 `assets/vision/sources/`，PNG 文件沿用原路径，使已有项目也能加载更新的素材。

平台使用内置 imagegen 编辑生成，提示要求：保留四层蓝灰色玻璃椭圆平台、原比例和逐层扩大的构图、透明背景、小红色向上箭头；清除缩略图中的模糊残影，不生成文字和图标。页面通过降低平台和远景透明度保留原稿的淡色风格。这次重建保持原构图，但并非逐像素复制。

编辑器左上角“返回主页”进入项目中心，同时触发当前项目保存；现有项目名称入口仍可用于切换项目。工具栏在窄屏下自动换行，按钮文字保持完整。

日出修订：顶部远景现为 imagegen 生成的 2173×724 透明素材，保留中央半圆太阳、细红色山脊、白色光芒和淡蓝色远景，无文字。提示要求仅重建日出背景、清晰轮廓和平滑渐变，不增加对象。页面保持图片比例并裁切显示，避免将太阳压扁；同样的 CSS 裁切用于导出。

完整检查覆盖全部 41 个图片对象。其余 26 个图标、徽章和协同箭头重绘为线条 SVG，并输出原尺寸 4 倍的 PNG，替换原路径。测试检查所有素材的宽高都不低于 1920×1080 画布中的显示尺寸，防止重新引入放大的低清缩略图。

缓存修订：图片 URL 添加 `VISION_ASSET_VERSION` 版本参数。新建页直接生成版本化 URL，打开已有项目或本地缓存时也更新模板内置图片的 URL；用户替换的图片及其文字、尺寸、位置保持原值。修改内置图片后必须更新该版本，连同 `vision-template.js`、其引用模块及 HTML 入口的缓存版本一起发布。线上检查曾发现旧地址仍显示 198×89，但加新查询参数的平台已为 1871×841，属于素材缓存与页面代码版本不一致。

当前边界：图片内部的渐变、图标路径和平台结构仍是位图，不能编辑内部矢量节点；浏览器与 PowerPoint 的字体排版可能不同。这是默认模板与现有编辑器的集成，不等于实现 Canva 的完整产品功能。

定向验证：`node --test tests/slide-vision-template.test.js`；修改的前端模块使用 `node --check` 检查语法。页面验证覆盖新建项目、增加内容页和指标文字编辑；实际两页 PPT 导出逐页检查到 33 个文字对象、41 个图片对象及四个指标标签。
