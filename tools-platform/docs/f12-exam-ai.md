# 题库与答题助手：可选 AI 作答

F12 扩展打包页面选择“题库与答题助手”，重新打包并安装扩展后，助手浮窗增加“🧠 AI 设置”。已有扩展需重新打包，并在保留扩展 ID 的前提下更新。平台运行中的内置工具如尚未更新，需通过现有系统工具更新入口同步本次源码。

## 配置与使用

1. 点击“添加模型”，选择协议、填写模型 ID、API 端点和 API Key；可添加多个模型，分别启用或停用。
2. 点击每个模型的“测试模型”。测试会真实调用该 API，用简单单选题检查连通性和答案格式。
3. 默认“题库优先”：当前题库或其他题库已有确认答案时，直接使用题库，未确认的题目才请求 AI。“AI 优先”会先用 AI 推荐，失败时回退题库及原猜答流程。
4. 每批默认 1 题，可设置 1–10 题。批量模式会先逐题翻页读取同一区段内的题目，再回到当前题，向所有启用模型并行发送这批题目，随后逐题应用推荐。
5. 勾选“开启 AI 思考”并保存，再点击原来的“自动答题”。关闭 AI 时沿用原答题流程。

Chat、Responses 和 Messages 均支持平台 AI 助手使用的 API 基址（如 `https://example.com/v1`），会按所选协议自动追加路径，也支持填写完整端点。域名根地址会补上 `/v1`；带自定义前缀的基址保留此前缀。填写方式：

| 协议 | 端点示例 |
| --- | --- |
| OpenAI Chat / Compatible | `https://api.openai.com/v1/chat/completions`，或兼容服务的完整 Chat Completions 端点 |
| OpenAI Responses | `https://api.openai.com/v1` 或 `https://api.openai.com/v1/responses` |
| Anthropic Messages | `https://api.anthropic.com/v1` 或 `https://api.anthropic.com/v1/messages` |
| Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta`；自动追加模型路径 |

适配使用供应商的标准 JSON 请求和非流式响应结构，参考 [OpenAI API](https://platform.openai.com/docs/api-reference)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)、[Gemini generateContent](https://ai.google.dev/api/generate-content)。自定义网关须提供相应兼容协议。这里的“AI 思考”表示调用模型辅助答题，不强制配置供应商专属的深度推理参数。

## 推荐、回退与数据

- 仅发送题目、题型、标记后的选项、已确认的错误经验和批次内部题号，不附带网站 Cookie、题库名称或整页内容。已识别的凭据字段会在题目文本内脱敏；API Key 仅通过供应商认证请求头使用。
- 模型必须返回规定的 JSON、题号及选项字母。单选/判断题只接受一个选项；多选题接受有效的选项组合。无法解析、选项越界或重复题号的推荐无效。
- 多个模型的有效推荐按完整选项组合投票，得票最多者胜出；平票或全部失败时回退原流程。部分模型失败时，其余有效结果仍可使用。
- 每次查询从当前题库中按题型、题干及完整选项匹配同一道题，附带已确认的错项和错误组合。错误记录按选项文字重新映射为当前选项字母，支持选项打乱。多选题答错只排除那个完整组合，除非已有明确错项证据，不会把组合中的单个选项全部排除。无对应选项的旧记录及未证实的猜测不会作为错误经验发送。
- 模型推荐在投票前及点击前都检查错误经验，已知错项或错误组合会被拒绝。需要在考试复盘页面点击“开始抓取”，让助手保存本次确认的错误，再用于后续 AI 查询。
- AI 推荐保存为疑似答案，等待后续复盘验证，不覆盖题库确认答案。AI 优先可以在本次作答中选择与确认答案不同的推荐。
- 扩展版的配置保存在加密保险库中，按网站来源隔离；API Key 与 AI 开关只留在受限的扩展 session 存储，不写入磁盘、题库、偏好、导出或日志。同一次浏览器会话中刷新可继续使用，手动锁定或重启浏览器后 Key 与 AI 开关清除。F12 模式的 Key 仍只保留当前脚本内存。
- “停止”会取消待处理请求；请求超时为 60 秒。不要在查询过程中手动切换题目，助手会在作答前校验当前题目。

## 扩展网络权限

新版加密题库助手使用 ISOLATED 注入及直接的扩展后台网络通道，不通过网页 postMessage 传递 Key 或模型请求；旧版非加密助手仍使用请求转发脚本。新版，支持 HTTPS 模型端点以及 `localhost` / `127.0.0.1` 的 HTTP 本地模型端点。为支持用户自由配置的 API 域名，此类包增加 HTTPS 网站访问权限；普通脚本包保持原有权限。认证请求不携带网站 Cookie，也不跟随重定向。

直接在 F12 控制台运行源码时使用浏览器 fetch，端点必须允许考试网站来源的 CORS；打包扩展通过后台请求通道跨域。测试调用和正式作答均可能产生供应商 API 费用。

## 日志与耗时统计

每条日志以固定宽度 `[HH:mm:ss.SSS]` 开头，时间采用浏览器本地时间。自动答题逐题记录 AI 思考耗时，题库直接命中或关闭 AI 时显示未调用 AI。

- 思考耗时指发出模型请求到返回并解析结果的实际等待时间，包含网络等待，不是供应商内部推理耗时。多模型并行查询按整批实际等待时间计一次，不叠加每个模型的请求时间。
- 多题一批时，各题日志展示共同等待时间及均摊时间。结束汇总的平均每题耗时为 AI 总等待时间除以实际送往 AI 的题目数，包含失败、无共识及预读取后尚未作答的题目。
- token 总量累加所有启用模型返回的用量。收到响应但答案格式无效时，其用量仍计入；供应商没有返回用量、请求失败或取消时显示“用量未知”，不会将这些请求当作零消耗。模型测试独立于答题任务，不计入本次任务汇总。
- token 字段支持 OpenAI Chat / Responses 的 `usage`、[Anthropic Messages usage](https://platform.claude.com/docs/en/api/messages/create) 和 [Gemini UsageMetadata](https://ai.google.dev/api/generate-content)。优先采用总 token 字段，避免重复计入其中已有的缓存/推理 token。
- 翻页延迟默认每次独立随机浮动 ±15%，浮动最多 200ms。输入 600ms 时约在 510–690ms；抓取、答题和 AI 批量预读取均使用该延迟。AI 请求超时和选项保持验证的等待不受影响。

## 窗体透明度与缩放

主助手窗体默认不透明度 50%（半透明）、整体缩放 50%。标题、日志、字体、按钮及间距一同等比缩放。点击右上角语言切换旁的齿轮，可以即时调整不透明度（20%–100%）和缩放比例（25%–150%），也可以恢复默认 50% / 50%。

外观设置自动保存在当前网站来源的浏览器偏好中，重新载入后继续生效。设置弹窗保持正常大小和清晰显示，方便调整。主窗体拖动按缩放后的实际位置计算；改变比例和视口尺寸时会限制位置，避免整个窗体移出屏幕。外观设置不修改 AI 模型配置或题库数据。

## 最近一场考试的 AI 思考日志

“AI 思考设置”新增“思考日志”按钮，运行中也可打开；运行中模型配置保持只读。默认友好视图按模型请求展示题目、题型、选项、错误经验、有效推荐、多模型共识、耗时和 token，附带模型实际返回的回答和思考/摘要字段。模型未返回的内部推理无法还原。

可切换“原始请求 / 响应”查看小字号 JSON，包括脱敏后的请求端点、请求头、请求体、响应、HTTP 状态和错误。HTTP 非成功响应及 JSON 格式错误也会记录，便于区分接口配置错误、网络失败和答案格式问题。“刷新”可更新运行中的日志。

每次启动自动答题会建立一场新的日志，覆盖上一场；AI 关闭或未调用时显示无请求。模型测试不覆盖考试日志。日志随当前网站来源的数据一起保存在加密保险库中，只保留最近一场，刷新页面后仍可查看；存储不可用时仅保留当前页面内存记录。容量限定约 100 万字符/500 条请求，超过时优先移除较早记录并提示；单个文本超过 48000 字符会明确标注截断。

保存前递归脱敏认证请求头、密码/Token/Key 字段、私钥和已配置的 API Key，包括响应或错误消息回显的 Key。日志不上传平台后端，不进入题库导出文件。诊断日志仍包含题目与模型返回内容。扩展版详情、AI 设置与原始日志显示在扩展独立窗口中，不放进考试网页的 DOM。

## 题库回顾：解析与翻译

进入“查看题库与标注”，点击“解析与翻译（全部英文题）”。先在 AI 设置中添加并启用至少一个模型，无需开启自动答题的 AI 思考开关。按钮处理当前题库中含英文的题目及全部选项，包含中英文混合题；不受搜索筛选限制。优先使用第一个启用模型，失败或返回缺失内容时尝试后续启用模型，每批最多 3 题。界面显示进度，并提供“停止解析”。

题干与选项的中文翻译直接显示在相应原文下方；题干下新增 AI 学习解析区域，用简单中文说明“考的是啥”和“为啥这么选”。有题库确认答案时，围绕确认答案进行解释，不能用模型返回的另一答案替换；若模型认为题库答案存在矛盾，应在解释中说明。没有确认答案时，推荐与解释明确标为未确认的 AI 建议。解析不会勾选选项，也不会写入正确答案字段。

学习解析随当前题库保存，刷新后可查看，中英文 JSON 题库导出/导入均保留。再次点击会复用已有有效解析，只处理尚未解析的英文题目。题目、选项或确认答案变化后，旧解析不再显示，重新点击可生成新的解析。解析和自动抓取/答题互斥；解析期间仍可手动标注答案，返回结果与当前标注不一致时跳过保存。

模型调用可能产生 API 费用；仅发送待解析题目、题型、选项和题库确认答案，按既有规则脱敏。翻译任务独立于最近一场自动答题的思考日志，不覆盖考试日志。

翻译的每批题目数沿用“AI 设置 → 每批题目数”，默认 1 题，翻译任务最多 3 题/批（即使自动答题设置更高）。这是一次请求包含的题目数量，不是并行请求数量：翻译批次依次执行，同一批优先请求第一个启用模型，失败时依次尝试后续模型。重试时会立即将上一轮结果替换为“解析中”进度，等待响应期间持续显示当前批次题目数。

### 详情中心多题库与学习资料导出

详情窗口的题库下拉选择独立于主界面：首次打开默认选中主界面题库，之后保留自己的选择。支持按题库名搜索、多选、全选搜索结果与反选搜索结果；清空搜索后操作范围为全部题库。表格显示来源题库，统计合计所选题库的题目。详情窗口的题目搜索只过滤显示，不缩小导出或解析范围。

标注答案和解析与翻译分别保存到题目的来源题库；解析期间锁定题库选择，返回时校验存储快照和题目内容，避免覆盖中途变化的数据。主界面抓取、自动答题仍使用主界面选择的题库。

详情中心支持直接导出全部所选题库为真正的 `.xlsx` Excel 工作簿或独立 HTML 学习手册，包含题库名、题型、原题与选项、中文翻译、确认答案、未确认 AI 建议、考点及答案解释。Excel 带表头冻结、筛选、自动换行与列宽；所有内容写为文本单元格，避免公式执行，每格遵守 Excel 的 32767 字符上限。HTML 采用卡片布局，支持手机阅读和打印，无外部资源依赖。导出在本地完成，不包含模型配置或 API Key。JSON 备份和恢复仍使用原有入口。

## 加密保险库与旧数据兼容

首次使用新版扩展需在独立的扩展窗口设置密码，默认 6 位数字 PIN，也可选择至少 16 位、包含字母/数字/符号的复杂密码（不额外强制大小写）；密码不交给考试网页。每次浏览器会话解锁一次，之后刷新、查看、抓取、答题不再要求密码。关闭浏览器或点击 🔒 锁定后需重新输入。密码无法找回，建议准备加密备份并妥善保管密码。

题库、翻译解析、配置与最近一次思考日志以 AES-256-GCM 加密后保存在扩展 `storage.local`，密钥来自 PBKDF2-SHA-256（600000 次、随机 16 字节 salt），每次保存生成新的 12 字节 IV。题库在磁盘只保存密文和解密参数；参数及版本/修订号通过 GCM 附加认证数据保护。源码不包含密码或密钥。解锁密钥与 API Key 只留在受限于扩展自身的 `storage.session`，服务工作线程重启不要求重新解锁，浏览器重启会清除。

旧题库自动迁移：读取当前网站来源的 `ScraperData_` 记录，写入加密保险库并重新解密验证成功后，才删除对应旧明文。相同名称且不同内容的旧题库另存为“旧题库迁移”版本；格式异常、未成功迁移或迁移期间发生变化的记录保留在原位置并提示。取消解锁、密码错误和存储失败都不会主动清空旧题库。旧 IndexedDB 思考日志也在加密保存成功后迁移删除原记录。其他网站数据不修改。每个网站来源保持题库隔离。

旧版单题库/多题库 JSON、中英文题库与学习解析仍能从详情窗口导入，导入成功提示在加密保存完成后显示。详情窗口提供“加密备份”，导出 `.vault.json`；可以通过同一导入入口恢复，如果备份来自其他保险库，需要创建该备份时的密码。普通 JSON、Excel 和 HTML 导出为了兼容和阅读仍是明文，不携带 API Key。

详情与 AI 设置在扩展独立窗口中打开，详情窗口的题库选择与主界面独立。多窗口数据通过无明文的变更通知同步；同时编辑导致修订冲突时拒绝覆盖已有保险库、保留当前未保存数据供 JSON 导出，并提示重新打开。主界面仍显示必要的任务状态和作答日志，浏览器/操作系统级监控仍可能看到运行时数据或屏幕；这里保护的是持久化数据和普通网站脚本访问，不承诺对受控浏览器绝对保密。

扩展增加 `unlimitedStorage` 权限，设有约 2400 万字符的保险库内容保护上限。容量界面显示当前来源的明文大小估算；密文有 Base64 和认证开销，实际可用空间由浏览器决定。保存失败会停止任务、提示导出当前窗口的 JSON 数据，不回退为明文保存。

F12 控制台模式需要从平台加载完整脚本（包含加密组件），在 HTTPS/localhost 下运行：同样加密本地存储，但没有扩展隔离，密码通过网页环境内的实体键盘或屏幕键盘输入；每次重新执行脚本/刷新需要解锁，不能提供扩展版对网页脚本的隔离保证。

升级应保留同一个扩展 ID。卸载扩展会删除它自己的存储，换目录安装无固定 ID 的本地包也可能变成另一个扩展；操作前请保存加密备份。历史题库只能从仍保留它们的浏览器来源或已有备份迁移，不能恢复已被用户清理的数据。


### 密码屏幕键盘

首次设置默认选择简单 PIN，要求恰好 6 位数字（保留开头的 0）；也可切换复杂密码，规则为至少 16 位及字母、数字、符号，不强制大小写混用。切换模式清空两次输入，避免误用其他模式已输入的密码。设置、解锁和加密备份的备用密码均支持实体键盘、粘贴及自带屏幕键盘；实体输入采用标准密码字段掩码，支持光标编辑、删除和 Enter 提交。

PIN 模式仅显示随机 0–9 数字键，不显示字母/符号页、空格或 Unicode 操作。复杂模式保留大小写、数字、完整 ASCII 符号及空格；也可通过实体输入法或 U+ 页输入其他 Unicode 字符。屏幕按键每次打开及切换字符组用加密随机数打乱，可手动再次打乱。

新保险库和新备份在密文记录中保存密码模式，模式也纳入 AES-GCM 附加认证数据，后续保存、导出、导入及解锁保持一致。没有模式字段的旧保险库按原有复杂键盘解锁，并沿用原密码和原认证格式；不会自动改为 PIN。复杂规则只用于新建复杂密码，旧密码、旧备份不因长度或组成不同而失效。当前会话一次解锁的流程不变。

6 位 PIN 只有一百万种组合，虽然沿用 PBKDF2-SHA-256 的 600000 次迭代，仍比长密码更容易被离线猜测；设置界面对此作简短提示。实体键盘输入不再规避传统键盘记录器。屏幕键盘也不能阻止截图、鼠标记录、恶意扩展或受控浏览器读取运行时内容。


### 详情窗口与重置

独立详情窗口随外部窗口首次及后续调整大小铺满可用空间，内层标题栏不再拖动或固定像素尺寸。顶部操作按钮与解析/停止按钮使用同一紧凑工具栏，窄窗口可水平滚动；题库选择展开时允许换行，避免遮挡选择列表。详情标题栏也提供语言切换，加密备份按钮随语言切换，不同时显示中英文。

“重置题库”通过自定义确认窗口执行，仅清空当前题库的题目、答案、错误记录和学习解析，保留题库名称及其他题库。任务运行时须先停止；取消不修改数据，确认后等待加密保存完成。

解锁窗口使用紧凑字号、间距和键盘尺寸，操作按钮固定高度；顶部可切换中文/英文，仅显示当前语言，避免双语导致的高度增长。

统计卡片支持单选过滤：点击总题数、题型、准确答案、仅疑似、待学习或含错误记录卡片后过滤下方表格，再点同一卡片取消，点击另一卡片切换。当前卡片高亮并标记按下状态。过滤与搜索词、所选题库共同生效；卡片计数始终展示所选题库的完整统计，标注答案或跨窗口数据更新后自动重新匹配。总题数不限制题目类别，保留搜索词。


### 自定义提示窗口

题库助手全部提示和确认（包括取消解锁、旧版本检测、空数据、导入确认/成功/失败、存储清理及保存失败）使用统一的自定义窗口，不调用浏览器 alert/confirm/prompt。提示按队列显示，支持 Escape、Tab 和按钮键盘确认，关闭后恢复焦点；文案使用纯文本，避免题库内容注入 HTML。窗口标题和按钮随语言切换。密码仍使用专用输入界面。

导入/清理的异步确认会检查等待期间题库是否变更或助手是否退出，变化时取消操作；同一窗口不并发执行多个导入。


### 解锁窗口的语言与尺寸

首次打开按浏览器界面语言选择：中文语言为中文，其他语言为英文。解锁窗口顶部可手动切换中英文，切换不清空密码或改变模式；手动选择保存在扩展本地的非敏感语言偏好中，锁定、重启浏览器后保持。主界面与详情界面的语言按钮使用同一偏好，打开的界面实时联动，题库仍按网站来源隔离。

扩展解锁窗口默认 520×740，内容使用紧凑布局；已检查 520×650 可用视口下，中英文的 PIN/复杂模式都能完整显示确认按钮和底部提示。更小的窗口仍保留滚动，不裁切内容。F12 模式使用本站来源的语言偏好及紧凑密码键盘。


### 一键导入与窗口控制

主界面点击“导入 JSON”立即选择文件，选择后自动打开独立详情窗口并继续导入确认，无需在详情窗口再次点击导入。取消文件选择不打开新详情窗口，取消导入确认不修改题库。加密备份也使用同一流程。详情窗口中的导入按钮保持直接选择文件。

跨窗口文件转交使用随机、一次性、来源绑定的票据；文件内容先用当前保险库密钥加密后暂存于受限扩展 session，不写入网页 localStorage 或磁盘明文，也不传给 AI。票据五分钟内有效，领取一次后删除；关闭目标窗口或锁定保险库会清除待转交记录。转交受浏览器 session 容量限制，失败时保留原文件及题库，并提示从详情窗口直接导入。

详情窗口右上角提供最小化、最大化/还原和关闭按钮，操作实际浏览器窗口，按钮提示随语言切换。[Chrome windows API](https://developer.chrome.com/docs/extensions/reference/api/windows)没有隐藏系统边框的参数；普通 Chrome/Edge 扩展的 popup 窗口可以隐藏浏览器工具栏，但保留操作系统标题栏与边框。
